# 진행 상황

> 기준: **v0.3.0** (2026-09-15)

## 한눈에

| 영역 | 상태 |
|---|---|
| 휴대폰·Windows 조작 앱 | ✅ 시뮬레이션으로 완성, 실차 연결 코드 준비됨 |
| PC 테스트 서버 | ✅ 네트워크 문제 흉내까지 가능 |
| 통신 규약 | ⚠️ 기본 동작만. **오래된 명령 차단·조종권·인증 없음** |
| 카트 펌웨어 (ESP32) | ❌ 없음 |
| 카트 서버 (Orange Pi) | ❌ 없음 |
| 실제 Wi-Fi 실측 | ❌ 아직 (USB로만 확인) |

## 준비된 것

### 조작 앱 (`lib/`)
- **화면**: 라이다 점군과 태그(사람) 위치, 배터리(%·전압)·모터 출력·전류·자세·근접 센서·라이다 유효율
- **조작**: 데드맨 조이스틱(누르는 동안만 명령), 수동/자동(태그 추종) 전환
- **연결 감시**: 텔레메트리가 0.5초 끊기면 연결 끊김으로 판정하고 조작 즉시 해제.
  끊겼다 복구돼도 스틱을 한 번 떼야 다시 조작, 자동은 스스로 재개하지 않음
- **휴대폰 상태**: 알림창·전화 때는 조이스틱만 해제, 홈·앱 전환·화면 꺼짐 때는 자동도 해제.
  조작 화면이 떠 있는 동안 화면 꺼짐 방지
- **빌드 환경 구분**: 시뮬레이션(기본) / 테스트 서버 / 실차. 화면 상단 배지로 항상 표시.
  실차 빌드에는 가짜 카트 코드와 고장 주입 패널이 **컴파일 단계에서 빠짐** (빌드 결과물 검사로 확인)
- **실제 연결**: WebSocket, 끊기면 0.5~5초 간격 재접속

### PC 테스트 서버 (`tool/cart_server.dart`)
- 앱의 테스트 서버 빌드가 붙는 가짜 카트. 앱 시뮬레이션과 같은 `CartSimulator` 사용
- 지연·흔들림·손실, Wi-Fi 음영(`hold`), 연결 끊기(`kick`), 가짜 카트 고장을 서버 창이나 PC 브라우저로 조작
- 200ms 넘게 늦게 도착한 명령을 경고
- **Orange Pi 서버를 만들 때 참고 구현**으로 쓸 수 있음

## 알려진 위험

| 위험 | 근거 | 해결 |
|---|---|---|
| 🔴 **음영 뒤 오래된 명령이 몰려와 그대로 실행됨** | 테스트 서버에서 조이스틱 명령 28개가 최대 1.5초 늦게 한꺼번에 도착. 카트는 구분할 방법이 없음 | v0.4.0: 명령 유효 기간 |
| 🔴 **명령 끊김 감시(200ms)가 카트에 없음** | 앱의 안전 설계 전체가 이것을 전제로 함 | ESP32 펌웨어 |
| 🔴 **제동장치 없음** | 구동 전원 차단은 제동이 아님. 경사에서 굴러갈 수 있음 | 하드웨어 |
| 🟠 여러 휴대폰이 동시에 조작 가능, 인증 없음 | 규약에 조종권·인증이 없음 | v0.4.0 |
| 🟠 방향 부호(좌/우)가 실물과 다를 수 있음 | 앱과 가짜 카트만 서로 맞춰져 있음 | 벤치 테스트에서 확인 |
| 🟠 UWB 모듈이 방향(`bearing_deg`)을 못 줄 수 있음 | 거리만 주는 모듈이 많음 | 모듈 사양 확인 |
| 🟠 휴대폰이 인터넷 없는 카트 Wi-Fi 대신 모바일 데이터로 통신 | 안드로이드 기본 동작 | 앱에서 Wi-Fi 고정 |
| 🟡 실제 Wi-Fi에서 0.5초 끊김 기준이 적절한지 모름 | USB로만 확인함 | 같은 Wi-Fi에서 실측 |

## 다음 단계

1. **v0.4.0 통신 규약 보강** — 명령 유효 기간(연결 시 시계 차이 보정), 조종권(한 번에 한 대), 규약 버전·인증 확인.
   PC 테스트 서버로 전부 검증 가능. 이 규약이 펌웨어가 따를 계약서가 됨
2. **카트 쪽 프로그램**
   - ESP32: 명령 200ms 끊김 감시, 모터 출력, 센서
   - Orange Pi: WebSocket 서버 (`tool/cart_server.dart` 참고)
   - 필요한 정보: ESP32 개발 환경(Arduino / ESP-IDF), Orange Pi 운영체제와 언어, 모터 드라이버 모델, 보드 간 연결 방식
3. **같은 Wi-Fi에서 실측** — PC와 휴대폰을 같은 Wi-Fi(핫스팟 가능)에 두고 테스트 서버로 확인
4. **벤치 테스트** — 바퀴를 띄운 상태에서 E-stop, 명령 끊김 감시, 좌우 방향 확인
